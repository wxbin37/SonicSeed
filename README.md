# 声因 Sonic Seed

声因是一款面向音乐创作者的 AI 灵感管理与 Demo 创作工具原型。

当前网页实现了移动端优先的可交互工作台，覆盖：

- 灵感收集箱：文字、哼唱、语音、图片、视频与导入入口
- AI 灵感整理：保留原文、生成标签、优化表达、扩写版本
- 灵感库：按类型、情绪、曲风、项目、状态筛选创作资产
- 灵感图谱：展示相似、改写、搭配、使用、衍生等关系
- Demo 工作台：组合历史灵感，试听概念片段，切换版本和素材角色

## 运行

```bash
pnpm install
pnpm run dev
pnpm run build
```

## 设计约束

页面严格按同目录 `design.md` 的 QQ 音乐移动端 token 落地：浅灰页面背景、实色白卡、品牌绿高亮、PingFang SC 字体栈、20px 大容器圆角、12px 间距节奏和柔和阴影。

视觉实现不使用渐变背景、不使用玻璃态、不使用 emoji 图标；界面图标来自 `lucide-react`。
